# Keuangan Digital

Aplikasi keuangan pribadi: transaksi, kartu kredit (tagihan & cicilan otomatis), langganan, tagihan rumah, dan pajak kendaraan.

- **Frontend:** HTML/CSS/JS statis di GitHub Pages
- **Backend:** Google Apps Script (REST API JSON) + Google Sheets & Drive
- **Keamanan:** login password (hash di Script Properties), token sesi HMAC, penguncian setelah 5 kali salah

Konfigurasi satu-satunya ada di `js/config.js` (URL Web App `/exec`). Panduan lengkap: `PANDUAN-INSTALASI.md`.
